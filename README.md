# GarudaResQ 

GarudaResQ is a disaster management and emergency response platform designed to help people and response teams during situations like floods, earthquakes, fires, landslides and cyclones.

The main idea behind the project is simple: **during a disaster, people need the right information at the right time.** GarudaResQ brings important things like emergency requests, safer routes, nearby shelters, shelter availability and resource coordination into one platform.

## What GarudaResQ Does

### For Citizens

* Receive disaster-related alerts and updates
* Find nearby shelters
* Check shelter availability
* Get safer route suggestions during emergencies
* Report emergency situations
* Get basic evacuation and safety guidance

### For Response Teams / Authorities

* Manage emergency requests
* Prioritize critical situations
* Manage shelters and their capacity
* Coordinate available resources
* Track affected areas
* Help with rescue and relocation operations

## Key Features

* Emergency alerts and requests
* Shelter management and occupancy tracking
* Safer route planning
* Location-based disaster information
* Coordination between citizens and response teams
* Resource and relief coordination
* Missing-person and emergency information
* Disaster-area data and visualization

## How It Works

A user can report or access information about an emergency through the platform. The system can then use the available disaster, location, shelter and route information to help the user find a suitable response option.

On the response side, authorities or organizations can manage emergency requests, shelters and available resources so that help can be coordinated more efficiently.

The project is designed in a modular way so that more features can be added as the system develops.

## Why We Built It

During a disaster, lack of information and coordination can make an already difficult situation worse. We wanted to build a system that focuses on connecting **people, information and emergency resources** in one place.

GarudaResQ is our attempt to apply programming, data structures and real-world problem solving to a problem that can have a meaningful impact.
